# Security Policy

## Current status

This repository is an offline Unity prototype with networking/backend contracts, not a deployed online service. Do not submit real player data, credentials, or private match information as an issue.

## Reporting a vulnerability

For a suspected secret leak, unauthorized profile/result/reward access, or other security issue, avoid filing exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled, or contact the repository owner privately through GitHub. Include affected commit/build, impact, and safe reproduction steps; redact tokens and personal data.

There is no published response-time SLA or production incident contact yet. See `Release/PB9/Threat-Review.md` for the release threat checklist.
